# Studie — Wetenschappelijke vorming

Studieomgeving voor bachelor 1, gebaseerd op de aangeleverde inleidingspresentatie Wetenschappelijke Vorming.

## Openen

Download `index.html` en open het bestand in een recente webbrowser (Chrome, Firefox, Edge of Safari).

## Inhoud

- 32 themalessen verdeeld over 7 thema's
- 56 quizvragen met feedback
- 91 originele dia's verwerkt in de studieomgeving
- Zoekfunctie en lokale studievoortgang

De website is één zelfstandig HTML-bestand. De originele PDF is niet afzonderlijk in deze repository opgenomen.

## Privacy

De studievoortgang wordt lokaal in de browser bewaard. **Deze GitHub-repository staat momenteel openbaar.** Wie toegang heeft tot de repository, kan ook de gepubliceerde website en de daarin opgenomen dia's bekijken.

## Herkomst

Gemaakt op basis van de aangeleverde cursus-PDF. Dit materiaal is een inleiding en vervangt niet alle afzonderlijke colleges.
